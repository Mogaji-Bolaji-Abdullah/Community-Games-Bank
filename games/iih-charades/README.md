# IIH Mix & Mingle — Charades Club

A single-host, browser-based charades tournament for the Ilorin Innovation Hub Mix & Mingle event.

## Play
Open [the charades game](./index.html) in a web browser, or use the [live deployed game](https://iih-mix-and-mingle-charades.vercel.app).

## Features
- Five themed rounds with 95 prompts
- 2–64 participating teams
- Team-by-team timed turns and scoring
- Word skip, round skip, pause, undo, and cancel game
- Qualification leaderboard and drumroll reveal
- Audience/projector mode, with secret words hidden
- Background ambience and an optional Spotify playlist embed
- Browser-based game progress and result export

## Hosting
This is a standalone HTML file with embedded styles and scripts, so no installation or build process is required. For local play, download `index.html` and open it in a modern browser.

**Note:** Keep the host controls and audience view in the same browser/device for synchronized game state. Music playback may require a user click.
