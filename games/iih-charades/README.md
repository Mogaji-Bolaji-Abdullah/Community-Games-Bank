# Charades Club

A free, host-controlled charades game for meetups, events and teams. Includes five rounds, timed turns, scoring, team qualification, a separate audience screen and ready-made prompts.

## Start

Open `index.html` in a browser or use the [live game](https://community-games-bank.vercel.app/games/iih-charades/). Add 2–64 teams, choose a timer and start at Round 1. The host sees words; the audience screen hides them.

## Use your own words

Before a game, open **Teams & words**, choose **Mix our words and mine**, **Use ready-made words only**, or **Use my words only**. Pick a round, add one phrase per line, then save. Custom words stay in the browser. Export/import a JSON word pack to share between browsers. The **My words only** mode needs custom prompts in every round.

## Notes

Audience and host screens synchronize between windows in the same browser/device, not independently across separate devices. Game scores and settings are stored locally. Always export an important word pack before clearing browser data.
